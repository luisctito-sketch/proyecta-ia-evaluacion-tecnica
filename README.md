# PROYECTA-IA — EVALUACIÓN TÉCNICA

Módulo de apoyo para Proyectos de Grado de Ingeniería Electrónica, posterior al chatbot de **Pruebas, Resultados y Análisis Técnico**.

## Nombre recomendado del repositorio

`proyecta-ia-evaluacion-tecnica`

URL esperada con GitHub Pages:

`https://luisctito-sketch.github.io/proyecta-ia-evaluacion-tecnica/`

## Propósito

Convertir los resultados de las pruebas en una evaluación técnica defendible mediante:

1. selección del elemento a evaluar;
2. selección de indicadores pertinentes;
3. cálculo de métricas;
4. comparación con una referencia externa;
5. criterio de aceptación;
6. interpretación técnica obligatoria;
7. vínculo con problema, Objetivo General y Objetivos Específicos.

## Alcance

La evaluación puede aplicarse a:

- hardware;
- software;
- firmware;
- sistema integrado;
- subsistemas;
- componentes o dispositivos específicos.

## Indicadores incluidos

Entre otros:

- exactitud de medición;
- precisión / repetibilidad;
- error absoluto, relativo y porcentual;
- MAE, RMSE y sesgo;
- incertidumbre;
- disponibilidad;
- MTBF;
- MTTR;
- tasa de operaciones exitosas;
- eficiencia;
- consumo energético y ciclo de trabajo;
- eficacia;
- productividad;
- estabilidad;
- porcentaje dentro de rango;
- sobreimpulso;
- tiempo de subida;
- tiempo de establecimiento;
- error estacionario;
- IAE, ISE, ITAE;
- latencia;
- variación del retardo;
- pérdida de paquetes;
- throughput;
- BER;
- RSSI / SNR / cobertura;
- tiempo de respuesta;
- uso de recursos;
- calidad de software/firmware;
- desempeño esencial;
- riesgo y controles;
- alarmas;
- seguridad técnica;
- calidad de servicio;
- calidad global ponderada.

## Regla metodológica fundamental

No se declara que un sistema “cumple”, “es preciso”, “es confiable” o “es eficiente” solo por obtener un resultado.

Cada indicador debe contener:

- definición;
- método o fórmula;
- datos utilizados;
- unidad;
- resultado;
- fuente externa;
- criterio/umbral;
- comparación;
- evidencia;
- interpretación técnica.

## Fuentes externas admisibles

- normas y recomendaciones;
- páginas oficiales;
- datasheets/fabricantes;
- libros y artículos técnicos;
- instrumentos de referencia;
- simulaciones;
- modelos matemáticos;
- línea base experimental;
- requisitos de diseño cuantificados y justificados.

## Referencias técnicas incorporadas

### Metrología
- JCGM 200:2012 — International Vocabulary of Metrology (VIM).
- JCGM/GUM — Guide to the expression of uncertainty in measurement.

### Software / firmware / ICT
- ISO/IEC 25010:2023 — Systems and software Quality Requirements and Evaluation (SQuaRE), product quality model.

### Telecomunicaciones
- ITU-T Y.1540 — IP packet transfer and availability performance parameters.
- ITU-T Y.1541 — Network performance objectives for IP-based services.

### Control y automatización
- Métricas de respuesta transitoria: rise time, settling time, overshoot, error estacionario e índices integrales del error, usando el criterio del diseño/modelo/bibliografía correspondiente.

### Electromedicina
- IEC 60601-1 — Basic safety and essential performance.
- IEC 62304 — Medical device software life cycle processes.
- ISO 14971:2019 — Risk management for medical devices.
